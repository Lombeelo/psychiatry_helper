Стек: Dart + Flutter на фронте, c++ + grpc на бэке, используются 2 БД, одна для персональных данных, другая для публичных. Пока что оба на Postgress, но нужен универсальный интерфейс.

Оценка происходит на основании:
	- скринкаста работы
	- исходного кода
	- реализованных сценариев
	- использованной архитектуры и стека
	- базовых тестов на устойчивость к нагрузкам
	- тестов на очевидные ошибки

------------------- // Сущности // -------------------------
Польз.:
	- перс данные.
	- Код. для отображения вместо перс. данных

Врач -> Польз.:
	- назначить Лекарство для Пациента
	- назначение Периодического входа в приложение
	- отслеживание Отметок пациента	
	- назначение прохождение Опросников
	- (переписка с Пациентом)
	- видит Статус Пациента


Пациент -> Пользователь.:
	- вести Дневник
	- вести "отметки о состоянии"
	- следует назначениям
	- имеет Статус: Зелёный, Жёлтый, Красный
	- Статус зависит от соблюдения Назначений
	- состояние Личного леса

Личный лес:
	- Нужна зарисовка.

Отметка о приёме Лекарства:
	- отметка времени в соответствии с назначением
	- дополнительная отметка о побочках


Помочник:
	- Поддерживает, валидирует после опросов/отметок

Дневник:
	- текстовая заметка
	- "мягкая рефлексия"


Назначение:
	- созадются Врачом
	- Имеют срок
	- пациент обязан отмечать их выполнение
	- может быть либо Лекарство, либо Опросник, либо просто Входы в приложение
	- учёт пропусков

Лекарство:
	- относится к Группе лекарств.
	- Эффекты
	- Дозировка
	- Противопоказания

Группа Лекарств:
	- побочные Эффекты
	- скорость наступления положительных Эффектов
	- Болезни

Эффект Лекарства:
	- Полярность
	- Частота


Помочник выбора Лекарств:
	- ИИ?


Опросник:
	- список Вопросов
	- На выходе подсчёт ответов и вывод одного из возможных результатов
	- результат сохраняется, Врач может самостоятельно посмотреть
	- (У врача) цветовая индикация пройденного теста
	- Опросник Эмоций тоже по сути Опросник.



*Геймификация:
	- Растёт дерево при различных действиях

*Коррекционная программа "ёжик в тумане":
	- автоматические Назначения с заданиями в Дневнике.


Уведомления (в шторке на телефоне, либо на ПК в приложении):
	- Врачу о Красном пациенте
	- Пациенту о приёме лекарства, о прохождении опросника

------------------- // Интерфейс // ---------------------

Экран 1: выбор врач или пациент
Экран 2: Вход в систему
Экран 3: Согласие с политиками


Врач:
Экран 4: Список пациентов, сбоку, как в ТГ. 
	- Индикатор-Светофор напротив каждого пациента
	- Справа-сверху возникают уведомления о пациентах
	- Посередине информация о Пациенте
	- Информация о пройденных опросниках
	- Открытие дневника
	- Открытие отметок об эмоциях

Экран 5: Меню выписываемых лекарств
	- Сначала группа
	- Внутри группы отдельное Лекарство
	- Сбоку инструкция
	- Ввод дозировки
	- Ввод Периода приёма
	- Должна быть помощь подбора на основании ответов пациента

Пациент:
Экран 4: Первичный сбор Анамнеза
Экран 5: 
	- Кнопка ведения Дневника
	*- Кнопка поддержки (возможно ИИ)
	*- Кнопка "мой лес" (геймификация)
	- Список Назначений
	- Мой врач

Экран 6: Дневник
	- записная книжка
	- предлагаются вопросы для рефлексии

Экран 7: Назначение
	- если Опросник, то просто проходится опросник с уведомлением-поддержкой или просьба обратиться к Врачу
	- если Лекарство, то отмечается его употребление + побочки
	- если Входы в приложение, то это просто кнопка

Экран 8: Поддержка "Ёжик"
	- Чат-бот
	- Ежик говорит хорошие слова и наставления.
	- "Я вижу, тебе нужна помощь, обратись к врачу"
